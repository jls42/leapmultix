LeapMultix fonctionne hors ligne en trois gestes

La PWA (Progressive Web App) offre le meilleur des deux mondes : la légèreté d’un site web et le confort d’une application installée. Aucun magasin d’applications à passer, aucune mise à jour à surveiller : les nouvelles versions arrivent automatiquement.

Installation rapide

Android

  1. Ouvrez LeapMultix dans Chrome ou Edge.
  2. Dans le menu du navigateur, touchez « Installer l’application » (ou « Ajouter à l’écran d’accueil »).
  3. Validez : l’icône apparaît sur l’écran d’accueil.

iOS / iPadOS

  1. Ouvrez le site dans Safari.
  2. Menu « Partager » → « Ajouter à l’écran d’accueil ».
  3. Renommez si besoin et confirmez.

Windows & macOS

  1. Depuis Chrome ou Edge, cliquez sur l’icône « Installer LeapMultix » dans la barre d’adresse.
  2. Autorisez la création du raccourci.
  3. L’application se lance dans une fenêtre dédiée.

Chromebook

  1. Ouvrez LeapMultix.
  2. Dans la barre d’adresse, choisissez « Installer ».
  3. Déployez l’application via Google Admin si nécessaire.

Après une première visite en ligne, l’application garde sur l’appareil ce que l’enfant a déjà ouvert : modes, images et traductions. Avant un trajet, ouvrez donc une fois en ligne les modes qu’il utilisera ; il pourra ensuite jouer dans l’avion ou dans une salle sans wifi.

Avantages clés

  • Temps de chargement réduit : l’essentiel est chargé en priorité, et chaque mode seulement au moment où l’enfant l’ouvre.
  • Mise à jour silencieuse : quand une nouvelle version est publiée, l’application la charge d’elle-même.
  • Paramètres persistants : thème, langue, volume et profils des enfants sont conservés même en mode avion.

Résolution des problèmes courants

  • L’option installer n’apparaît pas : assurez-vous d’utiliser un navigateur compatible PWA et que le site est chargé via HTTPS.
  • L’appli reste blanche hors ligne : ouvrez LeapMultix en ligne une fois par semaine pour rafraîchir le cache.
  • Besoin de libérer de l’espace : vous pouvez supprimer l’application depuis les réglages de l’appareil, puis la réinstaller. Attention : la progression des enfants n’est enregistrée que sur cet appareil, et la désinstallation peut l’effacer.

En pratique

Une fois LeapMultix installée, l’icône se comporte comme n’importe quelle application native. Pensez simplement à lancer l’app en ligne une fois par semaine pour récupérer les dernières mises à jour.

Si vous administrez plusieurs appareils (classe, médiathèque), gardez à portée les étapes d’installation ci-dessus pour les reproduire rapidement. Tous les profils et paramètres restent stockés sur l’appareil des enfants.
